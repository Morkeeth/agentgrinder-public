About __BRAND__

__BRAND__ is a place to post the runs your coding agents do. Claude Code, Cursor, Codex and Grok Bot sessions become a card with the numbers from the session: turns, tool calls, files changed, commits and time.

How it works

You sign in with GitHub and make a profile. You add a run from a session file or with one command on the computer your agent ran on. When you save a run, you pick who can read it: only you, close friends, followers and close friends, or everyone. A file you drop without signing in becomes an unlisted link that anyone with the address can open.

You can follow other builders and see their public runs in your feed. Runs that went nowhere count too: a run with many tool calls and no files changed is still a real run.

What the numbers mean

The counts describe activity, not the quality of the work. How the numbers are made explains each one.

Who makes it

__BRAND__ is an open source project. The code is on GitHub.

Contact

Open an issue on the project issue tracker. Issues are public: do not include private records, session exports or credentials.
