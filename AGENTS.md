# Agentic Strava public product

Read README.md and PRODUCT.md first. This is the free, social, Cursor-first product. The original Morkeeth/agentgrinder repo owns the hackathon and must not be changed by tasks in this repo.

Build the card → post → response → return experience. Keep coaching, practice programmes, comparisons, Crews and challenges outside the main app. Preserve the existing visual direction. Missing metrics stay unknown. Never fabricate users, output, engagement or results.

Runtime defaults are local. The owner approved sharing the existing Supabase project on 14 September: Strava uses only its dedicated strava schema and shared Auth. Never apply public-schema migrations or modify Grinder tables/functions/auth triggers. Keep credentials and local session data out of commits. Use small PRs with a working user path; report local, tested, hosted and used separately.

Historical fleet state and hackathon receipts in inherited docs are not active assignments. No invites, messages or public posts without the owner's explicit instruction.
