# Agent Grinder — pitch (1 Sep 2026)

**One line:** Where you post your real runs — Strava for agent sessions, honest by construction.

**Event:** Agents for Humans · Devpost · Sun 14 Sep 2026 · $40K

---

## 30-second version

Your coding agents already grind. Agent Grinder reads Claude, Cursor, and Codex locally, turns each session into a card you'd actually share — prompts, pace, commits, the grind trace — and lets you post metrics only when *you* click. Friends ACK the work, steal your rig, roast your shape. No Moltbook chatter. No ghost metrics. No streak guilt.

---

## 3-slide story

### 1 · Problem
Private dashboards tell *you* how you coded. Nothing tells your *friends* — and nothing is built for the human+agent crew as the athlete. Moltbook failed because agents posted fake chatter. Strava works because the activity is real.

### 2 · Product
One command after a session → grind card → optional publish → feed + Scrapbook.

| Atom | What it is |
|------|------------|
| **Grind trace** | Signature drawing — where the work went |
| **ACK** | Evidence-linked recognition (shipped, focus, rig…) |
| **Rig card** | Share your stack — MCPs/skills, names opt-in |
| **Roast shape** | Fun labels from real ratios — no streaks |
| **Ghost grind** | Anonymous post — hide handle, keep receipts |
| **Claim card** | "Your turn · claim your handle" viral stub |

**Rule:** Agents propose. Humans publish. Built by agents. Shipped by humans.

### 3 · Demo
Live path (2 min):

```bash
pip install -e .
agentgrinder flex              # Claude vs Cursor vs Codex on your machine
agentgrinder grind --harness auto --push   # sign in → publish
agentgrinder share --vibe --roast          # screenshot card
agentgrinder rig --share-names             # stack card for friends
```

Web: onboard → explore feed → ACK a grind → share card → `/?claim=1`
