# Segment 01 sample CLI

This folder is the complete repository surface for the first Agentic Strava segment. The CLI reads a UTF-8 text file and prints its line, word and character counts.

Run it:

```sh
python3 summary.py README.md
```

The open task is in [TASK.md](TASK.md). Start from the code as checked in and use your coding agent to make the requested change. The task is intentionally small so runs from different tools can be compared on the same work.
